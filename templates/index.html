Student Performance Prediction

An end-to-end machine learning project that explores student data, predicts total scores and performance categories, and lets you inspect exactly how each model works.

📈 EDA

Explore distributions, correlations, class balance, and feature relationships in the dataset.

🔮 Predict Performance

Enter a student's attendance and scores to predict their total score or performance category using any of the 8 trained models.

🔬 Analyze Models

Inspect hyperparameters, feature engineering, and detailed interpretation plots for every model.

Project Overview

  • Regression models (predicting total score): Linear Regression, XGBoost, Polynomial Regression
  • Classification models (predicting performance: fail / poor / average / good): Logistic Regression, Decision Tree, Random Forest, KNN, XGBoost
  • Features used: Attendance Rate, Quiz 1 Score, Quiz 2 Score, Assignment Score
